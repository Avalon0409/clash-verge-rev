# Clash Verge App Proxy

Прокси-клиент для приложений и процессов в Windows и macOS с отдельными подписками, аккаунтами Freecat и настройками DNS.

[Загрузки](https://github.com/Avalon0409/clash-verge-rev/releases) · [Документация](./usage_en.md) · [English](./README_en.md) · [简体中文](../README.md)

## Возможности

- Сохранение настроек приложения, временные настройки процессов и наследование.
- Маршрутизация по правилам или принудительный прокси, выбор подписки и узла для приложения.
- Вход в Freecat и обновление подписок; секреты хранятся в Keychain или Credential Manager.
- Глобальные настройки DNS и настройки подписок, TUN, системный прокси и резервные копии WebDAV.

Специальные сборки обновляются вручную из этого репозитория. Требуется macOS 12 или новее. Выберите систему и архитектуру, указанные в файлах выпуска.

Полные руководства поддерживаются на китайском и английском языках. Инструкции по сборке и участию находятся в руководстве разработчика.
