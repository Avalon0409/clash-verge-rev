# Clash Verge App Proxy

کلاینت پراکسی برای برنامه‌ها و فرایندها در Windows و macOS، با اشتراک‌های مستقل، حساب‌های Freecat و تنظیمات DNS.

[دریافت](https://github.com/Avalon0409/clash-verge-rev/releases) · [مستندات](./usage_en.md) · [English](./README_en.md) · [简体中文](../README.md)

## قابلیت‌ها

- ذخیره تنظیمات هر برنامه، تنظیمات موقت فرایند و ارث‌بری از فرایند والد.
- مسیریابی بر اساس قواعد یا پراکسی اجباری، با انتخاب اشتراک و گره برای هر برنامه.
- ورود به Freecat و به‌روزرسانی اشتراک؛ اطلاعات محرمانه در Keychain یا Credential Manager ذخیره می‌شوند.
- تنظیمات DNS سراسری و مخصوص اشتراک، TUN، پراکسی سیستم و پشتیبان‌گیری WebDAV.

نسخه‌های سفارشی به‌صورت دستی از همین مخزن به‌روزرسانی می‌شوند. macOS 12 یا جدیدتر لازم است. سیستم و معماری مشخص‌شده در فایل‌های انتشار را انتخاب کنید.

راهنماهای کامل به زبان چینی و انگلیسی نگهداری می‌شوند. برای ساخت و مشارکت، راهنمای توسعه را ببینید.
