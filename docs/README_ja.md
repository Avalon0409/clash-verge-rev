# Clash Verge App Proxy

Windows と macOS 向けのアプリ・プロセス別プロキシクライアント。個別サブスクリプション、Freecat アカウント、DNS 設定に対応します。

[ダウンロード](https://github.com/Avalon0409/clash-verge-rev/releases) · [ドキュメント](./usage_en.md) · [English](./README_en.md) · [简体中文](../README.md)

## 機能

- アプリ設定の保存と、実行中プロセスの一時設定・継承。
- アプリごとのルール分岐、強制プロキシ、サブスクリプションとノードの選択。
- Freecat ログインとサブスクリプション更新。認証情報は Keychain または Credential Manager に保存。
- 全体・サブスクリプション別 DNS 設定、TUN、システムプロキシ、WebDAV バックアップ。

独自配布版はこのリポジトリから手動で更新します。macOS 12 以降が必要です。配布ファイルに記載されたシステムとアーキテクチャを選んでください。
