# Clash Verge App Proxy

Cliente de proxy por aplicação e processo para Windows e macOS, com assinaturas independentes, contas Freecat e ajustes de DNS.

[Downloads](https://github.com/Avalon0409/clash-verge-rev/releases) · [Documentação](./usage_en.md) · [English](./README_en.md) · [简体中文](../README.md)

## Recursos

- Configurações persistentes por aplicação e substituições temporárias por processo.
- Roteamento por regras ou proxy forçado, com assinatura e nó por aplicação.
- Login e atualização de assinaturas Freecat; credenciais no Keychain ou Credential Manager.
- Ajustes de DNS globais e por assinatura, TUN, proxy do sistema e backup WebDAV.

As versões personalizadas usam atualização manual a partir deste repositório. O macOS requer a versão 12 ou posterior. Escolha o sistema e a arquitetura indicados nos arquivos da versão.

Os guias completos são mantidos em chinês e inglês. Consulte o guia de desenvolvimento para compilar ou contribuir.
