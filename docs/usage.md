# Clash Verge App Proxy 使用说明

## 安装与更新

从 [本项目 Releases](https://github.com/Avalon0409/clash-verge-rev/releases) 下载适合当前系统的 `app-proxy` 发行包。macOS 需要 12 或更新版本，Windows 按附件架构选择安装包。

自定义发行包采用手动更新。安装新版前可以导出配置或使用 WebDAV 备份；安装后在设置中确认加载客户端配套的内置核心。重建或更换核心后重新检查应用分流。

## 应用代理

1. 添加或导入一个订阅，确认所需节点可用。
2. 打开「应用代理」，开启应用分流，并按提示准备 TUN 和服务。
3. 在应用列表中选择目标应用，或手动添加 `.app` / EXE。
4. 为应用选择订阅、路由模式和节点，然后打开该应用的代理开关。
5. 在应用行、进程列表和连接页检查路由与流量。

「规则分流」使用选定订阅的规则，并可选择应用的代理节点；订阅中的直连和拒绝规则仍保留。「强制代理」使用为应用选择的节点。订阅或节点缺失时，需要重新选择可用目标。

未配置和关闭代理的 TUN 应用默认使用系统网络。系统代理另外影响遵循系统代理设置的程序；检查纯应用分流时关闭系统代理。

## 进程继承

应用配置长期保存。子进程沿父进程查找配置；macOS 应用包设置还覆盖包内进程。针对某个运行进程设置的临时覆盖只作用于该次进程实例，恢复继承后重新使用应用或父进程配置。

Windows 应用配置使用完整 EXE 路径。点击列表顶部的刷新按钮会检查保存的应用路径，清理已不存在的条目和配置，并重新扫描安装入口。新版路径需要重新选择和配置。进程快照会定期刷新，父子进程继续按现有配置继承。路径检查出现权限或访问错误时，刷新会报错并保留原配置。操作方法见 [Windows 应用更新](./faq.md#windows-application-updates)。

## Freecat 账号订阅

在订阅页面创建 Freecat 账号订阅，填写自己的 HTTPS 服务地址、账号和密码，然后登录并导入订阅。以后可以直接刷新该账号订阅。

密码、登录会话和订阅解密材料保存在 macOS Keychain 或 Windows Credential Manager 中。账号服务地址、邮箱和凭据引用随订阅配置保存。系统凭据存储失败或会话失效时，按提示重新登录。

## DNS 覆盖

全局 DNS 覆盖用于公共配置；订阅级 DNS 覆盖用于对应的独立订阅。应用选择订阅后，其订阅配置参与生成该应用的 DNS 设置。修改 DNS 后检查保存值和运行中的核心配置。

涉及应用 DNS 出口和 Windows 多网卡选路的修补在 [PR #1](https://github.com/Avalon0409/clash-verge-rev/pull/1) 中评审。需要排查该类问题时，反馈全局节点、应用节点、DNS 设置及复现步骤。

## 备份与隐私

可以导出配置或设置 WebDAV 备份。备份包含订阅和代理配置，需要由你选择保存位置或备份服务器。账号秘密保存在系统凭据库中，移动到另一台电脑后需要重新登录。

完整的数据流、日志和存储说明见 [PRIVACY.md](../PRIVACY.md)。

## 获取帮助

先查看 [常见问题](./faq.md)，再到 [本仓库](https://github.com/Avalon0409/clash-verge-rev) 查找已有反馈。反馈中提供实际发行包标签、系统版本、路由模式和复现步骤。
