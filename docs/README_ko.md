# Clash Verge App Proxy

Windows와 macOS용 앱 및 프로세스별 프록시 클라이언트입니다. 독립 구독, Freecat 계정과 DNS 설정을 지원합니다.

[다운로드](https://github.com/Avalon0409/clash-verge-rev/releases) · [문서](./usage_en.md) · [English](./README_en.md) · [简体中文](../README.md)

## 기능

- 앱 설정 저장, 실행 중인 프로세스의 임시 설정과 상속.
- 앱별 규칙 분기 또는 강제 프록시, 구독과 노드 선택.
- Freecat 로그인과 구독 갱신. 자격 증명은 Keychain 또는 Credential Manager에 저장됩니다.
- 전역 및 구독별 DNS 설정, TUN, 시스템 프록시와 WebDAV 백업.

사용자 지정 배포판은 이 저장소에서 수동으로 업데이트합니다. macOS 12 이상이 필요합니다. 릴리스 파일에 표시된 시스템과 아키텍처를 선택하세요.

전체 사용 설명서는 중국어와 영어로 유지합니다. 빌드와 기여 방법은 개발 안내를 참조하세요.
