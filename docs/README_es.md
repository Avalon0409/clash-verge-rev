# Clash Verge App Proxy

Cliente de enrutamiento por aplicación y proceso para Windows y macOS, con suscripciones independientes, cuentas Freecat y ajustes de DNS.

[Descargas](https://github.com/Avalon0409/clash-verge-rev/releases) · [Documentación](./usage_en.md) · [English](./README_en.md) · [简体中文](../README.md)

## Funciones

- Configuración persistente de la aplicación y ajustes temporales por proceso.
- Modos de reglas y proxy forzado, con una suscripción y un nodo por aplicación.
- Inicio de sesión y actualización de suscripciones Freecat; credenciales en Keychain o Credential Manager.
- Ajustes de DNS globales y por suscripción, TUN, proxy del sistema y copias WebDAV.

Los paquetes personalizados se actualizan manualmente desde este repositorio. macOS requiere la versión 12 o posterior. Elige la arquitectura indicada en los archivos de la versión.
